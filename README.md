# Портал для врачей

Веб-приложение для врачей с возможностью управления пациентами, создания планов лечения и загрузки медицинских фотографий.

## Возможности

- **Авторизация врачей** - регистрация и вход в систему
- **Управление пациентами** - добавление, просмотр и редактирование данных пациентов
- **Планы лечения** - создание и ведение планов лечения для каждого пациента
- **Загрузка фотографий** - загрузка и просмотр медицинских фотографий пациентов
- **Безопасность** - JWT аутентификация, хеширование паролей

## Технологии

### Backend
- Python 3.8+
- Flask - веб-фреймворк
- SQLAlchemy - ORM для работы с базой данных
- Flask-JWT-Extended - JWT аутентификация
- SQLite - база данных (можно заменить на PostgreSQL)

### Frontend
- HTML5
- CSS3
- Vanilla JavaScript
- Fetch API для работы с REST API

## Установка и запуск

### Предварительные требования

- Python 3.8 или выше
- pip (менеджер пакетов Python)

### Шаг 1: Клонирование репозитория

```bash
git clone <url-репозитория>
cd eliz
```

### Шаг 2: Установка backend

```bash
cd backend

# Создание виртуального окружения
python3 -m venv venv

# Активация виртуального окружения
# На Linux/Mac:
source venv/bin/activate
# На Windows:
# venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt

# Создание файла конфигурации (опционально)
cp .env.example .env
# Отредактируйте .env и установите свои секретные ключи
```

### Шаг 3: Запуск backend сервера

```bash
# Находясь в директории backend с активированным venv
python app.py
```

Backend сервер запустится на `http://localhost:5000`

### Шаг 4: Запуск frontend

Откройте новый терминал:

```bash
cd frontend

# Запуск простого HTTP сервера на Python
python3 -m http.server 8000
```

Или используйте любой другой веб-сервер по вашему выбору.

Frontend будет доступен на `http://localhost:8000`

## Использование

### 1. Регистрация врача

1. Откройте браузер и перейдите на `http://localhost:8000`
2. Нажмите "Зарегистрироваться"
3. Заполните форму регистрации:
   - Имя пользователя
   - Email
   - ФИО
   - Специализация
   - Пароль
4. Нажмите "Зарегистрироваться"

### 2. Вход в систему

1. Введите имя пользователя и пароль
2. Нажмите "Войти"

### 3. Добавление пациента

1. В главном меню нажмите "Добавить пациента"
2. Заполните информацию о пациенте:
   - ФИО
   - Дата рождения
   - Телефон
   - Email
   - Анамнез
3. Нажмите "Добавить"

### 4. Просмотр и управление пациентом

1. Нажмите на карточку пациента в списке
2. Вы увидите полную информацию о пациенте
3. Можете добавить план лечения:
   - Нажмите "Добавить план лечения"
   - Заполните данные плана
   - Укажите диагноз, препараты, процедуры
   - Установите статус и даты

### 5. Загрузка фотографий

1. На странице пациента найдите раздел "Фотографии"
2. Нажмите "Выбрать фото"
3. Выберите изображение (PNG, JPG, JPEG, GIF)
4. Добавьте описание (опционально)
5. Нажмите "Загрузить"

## API Endpoints

### Авторизация

- `POST /api/register` - Регистрация врача
- `POST /api/login` - Вход в систему
- `GET /api/me` - Получить данные текущего врача

### Пациенты

- `GET /api/patients` - Список пациентов врача
- `GET /api/patients/:id` - Данные конкретного пациента
- `POST /api/patients` - Добавить пациента
- `PUT /api/patients/:id` - Обновить данные пациента
- `DELETE /api/patients/:id` - Удалить пациента

### Планы лечения

- `GET /api/patients/:id/treatment-plans` - Планы лечения пациента
- `POST /api/patients/:id/treatment-plans` - Создать план лечения
- `PUT /api/treatment-plans/:id` - Обновить план лечения
- `DELETE /api/treatment-plans/:id` - Удалить план лечения

### Фотографии

- `GET /api/patients/:id/photos` - Фотографии пациента
- `POST /api/patients/:id/photos` - Загрузить фотографию
- `DELETE /api/photos/:id` - Удалить фотографию
- `GET /api/uploads/:filename` - Получить файл

## Безопасность

- Пароли хешируются с использованием Werkzeug
- JWT токены для аутентификации
- CORS настроен для работы между frontend и backend
- Ограничение размера загружаемых файлов (16 МБ)
- Проверка типов загружаемых файлов

## Разработка

### База данных

По умолчанию используется SQLite. Для продакшена рекомендуется PostgreSQL:

1. Установите PostgreSQL
2. Создайте базу данных
3. Обновите `DATABASE_URL` в `.env`:
   ```
   DATABASE_URL=postgresql://username:password@localhost/doctors_portal
   ```

### Миграции

При изменении моделей базы данных:

```bash
# Удалите старую БД (только для разработки!)
rm doctors_portal.db

# Перезапустите приложение для создания новых таблиц
python app.py
```
